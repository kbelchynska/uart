# Модуль 4.1. UART комунікація між мікроконтролерами

Двосторонній обмін по UART між **ESP32-S3-DevKitM-1** та **STM32F103C8 (Blue Pill)**:

1. Натискання кнопки на ESP32 → перемикається світлодіод на STM32.
2. Натискання кнопки на STM32 → перемикається світлодіод на ESP32.

## Протокол

UART 115200 8N1. Кожне натискання кнопки (з debounce 50 мс) надсилає один байт `'T'` (toggle).
Отримавши `'T'`, інша плата інвертує стан свого світлодіода. Протокол однаковий в обидва боки.

## Підключення

| ESP32-S3              | STM32 Blue Pill  |
|-----------------------|------------------|
| GPIO17 (TX)           | PA10 (USART1 RX) |
| GPIO18 (RX)           | PA9 (USART1 TX)  |
| GND                   | GND              |

Обидві плати працюють на логіці 3.3 В, тому рівні узгоджувати не потрібно.

| Плата | Кнопка                          | Світлодіод                       |
|-------|---------------------------------|----------------------------------|
| ESP32 | GPIO0 (BOOT), INPUT_PULLUP      | GPIO2 → резистор 220 Ом → LED → GND |
| STM32 | PB12 → кнопка → GND, INPUT_PULLUP | PC13 (вбудований, active LOW)  |

## Структура

- [esp32/](esp32/) — PlatformIO-проєкт для ESP32-S3 (лог подій у Serial Monitor, 115200).
- [stm32/](stm32/) — PlatformIO-проєкт для Blue Pill (заливка через ST-Link).
